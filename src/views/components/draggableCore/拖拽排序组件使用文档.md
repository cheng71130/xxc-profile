
# DraggableCore 使用文档

## 📦 组件简介

`DraggableCore` 是一个基于 Vue3 + TypeScript 的拖拽排序组件，支持列表/网格布局、跨容器拖拽、拖拽手柄、克隆模式等功能。

## ✨ 核心特性

- 🎯 **列表/网格布局** - 支持 `list` 和 `grid` 两种布局模式
- 🔄 **跨容器拖拽** - 相同 `group` 的容器间可互相拖拽
- 📋 **克隆模式** - 拖拽时复制数据而非移动
- 🎨 **拖拽手柄** - 可选的拖拽手柄，精确控制拖拽区域
- 🗑️ **删除功能** - 内置删除按钮支持
- 🎭 **动画效果** - 流畅的拖拽动画和占位指示
- 🎪 **自定义插槽** - 完全自定义内容、手柄、空状态

```vue

    <DraggableCore v-model="list" :item-key="'id'">
        <template #default="{ item, index }">
            <div>{{ index + 1 }}. {{ item.name }}</div>
        </template>
    </DraggableCore>
</template>
```

### 4. 跨容器拖拽

## 📋 Props 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `modelValue` | `any[]` | `[]` | 数据列表（v-model） |
| `itemKey` | `string \| Function` | `'id'` | 数据项唯一标识 |
| `disabled` | `boolean` | `false` | 是否禁用拖拽 |
| `animation` | `string` | `'flip-list'` | 动画名称 |
| `handle` | `boolean` | `false` | 是否启用拖拽手柄 |
| `removable` | `boolean` | `false` | 是否显示删除按钮 |
| `group` | `string` | `'default'` | 拖拽组名（相同组可跨容器） |
| `clone` | `boolean` | `false` | 是否克隆模式 |
| `layout` | `'list' \| 'grid'` | `'list'` | 布局模式 |
| `gap` | `number` | `12` | 项目间距（px） |
| `columns` | `number` | `3` | 网格列数 |
| `emptyText` | `string` | `'暂无数据，拖拽添加'` | 空状态提示 |
| `showPlaceholder` | `boolean` | `true` | 是否显示占位指示线 |
| `ghostClass` | `string` | `''` | 拖拽时的样式类 |
| `chosenClass` | `string` | `''` | 选中时的样式类 |
| `dragClass` | `string` | `''` | 拖拽中的样式类 |

## 🎪 Slots 插槽

| 插槽名 | 参数 | 说明 |
|--------|------|------|
| `default` | `{ item, index }` | 默认内容插槽 |
| `handle` | `{ item, index }` | 拖拽手柄插槽 |
| `remove` | `{ item, index }` | 删除按钮插槽 |
| `empty` | - | 空状态插槽 |

## 📢 Events 事件

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `update:modelValue` | `value: any[]` | 数据更新 |
| `change` | `{ oldIndex, newIndex, item }` | 同容器排序变化 |
| `add` | `{ item, newIndex }` | 从其他容器添加 |
| `remove` | `{ item, oldIndex }` | 移动到其他容器 |
| `start` | `{ item, index }` | 开始拖拽 |
| `end` | `{ item, oldIndex, newIndex }` | 结束拖拽 |

## ⚠️ 注意事项

1. **itemKey 必须唯一** - 确保每个数据项的 `itemKey` 唯一，否则可能导致拖拽异常
2. **跨容器拖拽** - 必须设置相同的 `group` 属性
3. **克隆模式** - 源容器设置 `clone: true`，数据不会被删除
4. **v-model** - 使用 `v-model` 或 `@update:modelValue` 保持数据同步
5. **深色背景** - 组件已针对深色背景优化，如需浅色背景请自定义样式
6. **性能优化** - 大量数据时建议使用虚拟滚动或分页

## 🐛 常见问题

### Q: 拖拽后数据不更新？
**A:** 确保使用了 `v-model` 或监听 `@update:modelValue` 事件

### Q: 跨容器拖拽失败？
**A:** 检查两个容器的 `group` 属性是否相同

### Q: 拖拽手柄不工作？
**A:** 确保设置了 `:handle="true"` 并提供了 `#handle` 插槽

### Q: 如何实现拖拽复制而不移动？
**A:** 在源容器设置 `:clone="true"`

### Q: 占位线位置不对？
**A:** 组件已修复占位线逻辑，确保使用最新版本

### Q: 如何禁用某些项的拖拽？
**A:** 在数据项中添加 `disabled: true` 属性

### Q: 动画效果如何自定义？
**A:** 通过 `animation` 属性指定动画名称，并在 CSS 中定义对应的过渡效果

### Q: 如何获取拖拽后的完整数据？
**A:** 监听 `@change` 或 `@end` 事件，或直接使用 `v-model` 绑定的数据

## 🎯 最佳实践

1. **数据不可变性** - 始终返回新数组而非修改原数组
2. **唯一标识** - 使用稳定的唯一 ID 作为 `itemKey`
3. **事件处理** - 合理使用事件进行日志记录、API 调用等
4. **样式隔离** - 使用 scoped 样式避免全局污染
5. **类型安全** - 充分利用 TypeScript 类型检查
6. **性能监控** - 大数据量时注意性能监控和优化
