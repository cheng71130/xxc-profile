## 组件简介

`LazyImage` 是一个功能强大的 Vue3 图片懒加载组件，提供了骨架屏、渐进式加载、错误处理、重试机制等完整的图片加载解决方案。

### 技术栈

- Vue 3.x (Composition API)
- TypeScript
- SCSS

---

## 核心特性

### ✨ 主要功能

- **懒加载** - 基于 IntersectionObserver 的视口懒加载
- **骨架屏** - 精美的加载占位动画
- **渐进式加载** - 先加载缩略图，再加载高清图
- **WebP 降级** - 自动检测浏览器支持并降级到 JPG
- **错误处理** - 失败重试机制和备用图片支持
- **加载进度** - 可选的加载进度显示
- **自定义插槽** - 支持自定义占位符、错误提示、遮罩层
- **响应式** - 完美支持不同尺寸和宽高比
- **性能优化** - 防抖、超时控制、内存释放

## 安装配置

### 1. 复制组件文件

将 `LazyImage.vue` 组件文件复制到项目中：

```
src/
└── components/
    └── LazyImage.vue
```

### 2. 全局注册（可选）

**main.ts / main.js**

```typescript
import { createApp } from 'vue';
import App from './App.vue';
import LazyImage from './components/LazyImage.vue';

const app = createApp(App);
app.component('LazyImage', LazyImage);
app.mount('#app');
```

### 3. 局部引入

```vue
<script setup>
import LazyImage from '@/components/LazyImage.vue';
</script>
```

## Props 属性

### 基础属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `src` | `string` | **必填** | 图片地址 |
| `alt` | `string` | `''` | 图片描述 |
| `fallbackSrc` | `string` | - | 加载失败时的备用图片 |

### 尺寸控制

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `width` | `string \| number` | - | 容器宽度（带单位或数字） |
| `height` | `string \| number` | - | 容器高度（带单位或数字） |
| `aspectRatio` | `string \| number` | - | 宽高比（如 `16/9` 或 `1.78`） |
| `fit` | `'fill' \| 'contain' \| 'cover' \| 'none' \| 'scale-down'` | `'cover'` | 图片填充方式 |

### 功能开关

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `lazy` | `boolean` | `true` | 是否启用懒加载 |
| `showSkeleton` | `boolean` | `true` | 是否显示骨架屏 |
| `showMask` | `boolean` | `false` | 是否显示悬停遮罩层 |
| `showRetry` | `boolean` | `true` | 失败时是否显示重试按钮 |
| `progressive` | `boolean` | `false` | 是否启用渐进式加载 |
| `webpFallback` | `boolean` | `true` | 是否启用 WebP 降级 |

### 高级配置

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `threshold` | `number` | `100` | 懒加载触发距离（像素） |
| `timeout` | `number` | `30000` | 加载超时时间（毫秒） |
| `errorMessage` | `string` | `'图片加载失败'` | 错误提示文本 |
| `thumbnailWidth` | `number` | `100` | 缩略图宽度（渐进式加载） |
| `imageWidth` | `number` | - | 主图宽度（用于 URL 参数） |

## 事件

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `load` | `Event` | 图片加载成功时触发 |
| `error` | `Error` | 图片加载失败时触发 |

### 事件使用示例

```vue
<LazyImage
  src="/image.jpg"
  @load="handleLoad"
  @error="handleError"
/>

<script setup>
const handleLoad = (event) => {
  console.log('图片加载成功', event);
};

const handleError = (error) => {
  console.error('图片加载失败', error);
};
</script>
```

## 插槽

### 默认插槽

组件不提供默认插槽，所有内容通过具名插槽插入。

### 具名插槽

#### `placeholder` - 自定义加载占位符

替换默认的加载动画。

```vue
<LazyImage src="/image.jpg" :show-skeleton="false">
  <template #placeholder>
    <div class="custom-loader">
      <span>加载中...</span>
    </div>
  </template>
</LazyImage>
```

#### `error` - 自定义错误提示

自定义错误状态的显示内容。

```vue
<LazyImage src="/image.jpg">
  <template #error="{ retry }">
    <div class="custom-error">
      <p>加载失败！</p>
      <button @click="retry">点击重试</button>
    </div>
  </template>
</LazyImage>
```

**插槽参数：**
- `retry: Function` - 重试加载方法

#### `mask` - 悬停遮罩层

鼠标悬停时显示的遮罩内容。

```vue
<LazyImage src="/image.jpg" :show-mask="true">
  <template #mask>
    <div class="image-actions">
      <button>预览</button>
      <button>下载</button>
    </div>
  </template>
</LazyImage>
```

#### `badge` - 图片角标

显示在图片右上角的标签。

```vue
<LazyImage src="/image.jpg">
  <template #badge>
    <span class="new-badge">NEW</span>
  </template>
</LazyImage>
```

## 方法

通过 `ref` 访问组件实例方法。

### `retry()`

手动触发重试加载。

```vue
<LazyImage ref="imageRef" src="/image.jpg" />

<script setup>
import { ref } from 'vue';

const imageRef = ref();

const handleRetry = () => {
  imageRef.value.retry();
};
</script>
```

### `reload()`

完全重新加载图片（重置所有状态）。

```vue
<script setup>
const handleReload = () => {
  imageRef.value.reload();
};
</script>
```

## 常见问题

### Q1: 图片不显示/一直加载中？

**可能原因：**
1. 图片 URL 错误或无法访问
2. 跨域问题（CORS）
3. 网络超时

**解决方法：**
```vue
<!-- 增加超时时间并添加备用图 -->
<LazyImage
  src="/image.jpg"
  fallback-src="/placeholder.jpg"
  :timeout="60000"
  @error="handleError"
/>
```

### Q2: 懒加载不生效？

**检查项：**
1. 确认 `lazy` 属性为 `true`
2. 检查容器是否在视口内
3. 浏览器是否支持 IntersectionObserver

**解决方法：**
```vue
<!-- 禁用懒加载测试 -->
<LazyImage
  src="/image.jpg"
  :lazy="false"
/>
```

### Q3: 如何预加载重要图片？

```vue
<script setup>
import { onMounted } from 'vue';

onMounted(() => {
  // 预加载关键图片
  const img = new Image();
  img.src = '/critical-image.jpg';
});
</script>

<LazyImage
  src="/critical-image.jpg"
  :lazy="false"
/>
```

### Q4: 如何批量重试加载失败的图片？

```vue
<template>
  <div>
    <LazyImage
      v-for="img in images"
      :key="img.id"
      :ref="el => imageRefs[img.id] = el"
      :src="img.url"
    />
    
    <button @click="retryAll">重试全部</button>
  </div>
</template>

<script setup>
import { ref } from 'vue';

const imageRefs = ref({});

const retryAll = () => {
  Object.values(imageRefs.value).forEach(imgRef => {
    imgRef?.retry();
  });
};
</script>
```

### Q5: 组件支持 TypeScript 吗？

是的，组件完全使用 TypeScript 编写，提供完整的类型支持。

```typescript
import type { Ref } from 'vue';
import LazyImage from '@/components/LazyImage.vue';

const imageRef: Ref<InstanceType<typeof LazyImage> | null> = ref(null);

const reload = () => {
  imageRef.value?.reload();
};
```
